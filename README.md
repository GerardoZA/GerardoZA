Hi! I'm [@GerardoZA](https://github.com/GerardoZA) (Gerardo Zapata) 👋
I'm a bioinformatician at the [Canadian Centre for Computational Genomics (C3G)](https://computationalgenomics.ca/) in Montréal, Canada 🇨🇦
I build and run NGS pipelines on the [Digital Research Alliance of Canada](https://alliancecan.ca/) HPC clusters. Most of that work goes into [GenPipes](https://github.com/c3g/GenPipes), where I've added deepTools coverage tracks, SortMeRNA and RNA-SeQC2 to the RNA-seq pipeline and deepTools QC to the ChIP-seq pipeline. I also build [ChIP_Reporting](https://github.com/GerardoZA/ChIP_Reporting) (HTML reports for ChIP-seq & ATAC-seq results) and [PARPAL](https://github.com/c3g/PARPAL) (a Shiny web app), and recently added a DNA-only mode to an [oncoanalyser → cBioPortal](https://github.com/GerardoZA/nextflow-cbioportal_GZ) Nextflow pipeline.
 
* 🧬 **NGS:** RNA-seq, ChIP-seq, ATAC-seq, cancer WGS/WTS ([oncoanalyser](https://github.com/nf-core/oncoanalyser) → [cBioPortal](https://www.cbioportal.org/))
* 💻 **Languages:** Python (pipelines, Shiny apps), R / R Markdown (reports), Bash (SLURM scripts), Nextflow DSL2 / Groovy
